# نظام إدارة ملفات المرضى في المستشفيات

نظام ويب لإدارة ملفات المرضى (البيانات الأساسية، الزيارات، نتائج الفحوصات) مع صلاحيات حسب الدور وسجل تدقيق محمي من التلاعب.

## التقنيات
- **Backend:** Python 3.8+ و Flask و SQLite
- **Frontend:** HTML5 و CSS3 و JavaScript و Bootstrap 5 (RTL) — تُحمَّل من CDN فتحتاج اتصال إنترنت عند التشغيل
- **الأمان:** hashlib (PBKDF2-HMAC-SHA256 و SHA-256) و secrets
- **الاختبار:** pytest

## التشغيل
```bash
pip install -r requirements.txt
python manage.py seed-demo     # حسابات وبيانات تجريبية (اختياري)
python app.py                  # ثم افتح http://127.0.0.1:5000
```
لإنشاء مستخدم حقيقي بدل التجريبي: `python manage.py create-user`

حسابات التجربة (كلمة المرور لكلها `Demo12345`): `admin` و `doctor1` و `nurse1` و `reception1`.

## الاختبارات
```bash
python -m pytest
```

## بصمة السلامة (SHA-256)
كل ملف مريض له بصمة SHA-256 تُحسب من بياناته وزياراته ونتائج فحوصاته معًا، وتُحدَّث تلقائيًا مع كل تعديل مشروع من داخل النظام.
- عند فتح ملف المريض يعيد النظام حساب البصمة ويقارنها بالمخزَّنة: إذا تطابقت تظهر شارة «الملف سليم»، وإذا اختلفت يظهر تحذير أحمر ويُسجَّل `INTEGRITY_FAIL` في سجل التدقيق.
- يستطيع المدير فحص كل الملفات دفعة واحدة من صفحة «سجل التدقيق» (زر «فحص سلامة ملفات المرضى»)، أو من سطر الأوامر: `python manage.py verify`
- يكتشف الفحص أي تعديل أو حذف أو إضافة مباشرة في قاعدة البيانات خارج النظام.
- قواعد البيانات القديمة (قبل إضافة الميزة) تُرحَّل تلقائيًا ويُحسب لها بصمات عند أول تشغيل.

## ملاحظات أمنية
- كلمات المرور تُخزَّن بـ PBKDF2-HMAC-SHA256 مع Salt عشوائي لكل مستخدم (100,000 دورة).
- يُقفل الحساب 15 دقيقة بعد 5 محاولات دخول فاشلة.
- الرقم الوطني يُخزَّن مجزَّأً (SHA-256) مع آخر 4 أرقام فقط للعرض.
- كل عملية (دخول، عرض، تعديل، حذف) تُسجَّل في سجل تدقيق مترابط التجزئة، ويمكن للمدير التحقق من سلامته من صفحة «سجل التدقيق».
- حماية CSRF على كل النماذج، وترويسات أمان (CSP و X-Frame-Options)، واستعلامات SQL معلَّمة (parameterized).
- للنشر الفعلي: عيّن `SECRET_KEY` في متغيرات البيئة، وشغّل الخادم خلف HTTPS وخادم إنتاج مثل gunicorn بدل `python app.py`.

```
audit.py        سجل التدقيق والتحقق من السلسلة
integrity.py    بصمة SHA-256 لملف المريض وفحص السلامة
manage.py       إنشاء المستخدمين والبيانات التجريبية
templates/      صفحات HTML (Jinja2)
static/         CSS و JavaScript
tests/          اختبارات pytest
```
